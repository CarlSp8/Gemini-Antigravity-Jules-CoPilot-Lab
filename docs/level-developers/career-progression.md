# Career Progression Guide

## Overview
This guide helps developers plan and navigate their career progression on GitHub and in software development.

## Progression Paths

### Path 1: Individual Contributor (IC)

```
Junior Developer (IC1)
    ↓
Mid-Level Developer (IC2)
    ↓
Senior Developer (IC3)
    ↓
Staff Developer (IC4)
    ↓
Principal Developer (IC5)
    ↓
Distinguished Engineer (IC6)
```

### Path 2: Technical Leadership

```
Senior Developer
    ↓
Tech Lead
    ↓
Engineering Manager
    ↓
Senior Engineering Manager
    ↓
Director of Engineering
    ↓
VP of Engineering
```

## Timeline Expectations

### Typical Progression
- **Junior → Mid:** 2-3 years
- **Mid → Senior:** 3-4 years
- **Senior → Staff:** 3-5 years
- **Staff → Principal:** 4-6 years

*Note: These are guidelines. Progression depends on performance, growth, and opportunities.*

## Advancement Criteria

### To Mid-Level Developer
- **Technical:**
  - Deliver features independently
  - Write maintainable code consistently
  - Create comprehensive tests
  - Debug complex issues
  
- **Collaboration:**
  - Provide quality code reviews
  - Help junior developers
  - Contribute to technical discussions
  
- **Impact:**
  - Complete projects on time
  - Reduce bugs in your code
  - Improve team productivity

### To Senior Developer
- **Technical:**
  - Design system components
  - Lead technical implementations
  - Establish best practices
  - Expert in your domain
  
- **Collaboration:**
  - Lead code reviews
  - Mentor multiple developers
  - Drive technical decisions
  
- **Impact:**
  - Deliver complex projects
  - Improve team technical standards
  - Influence product direction

### To Staff Developer
- **Technical:**
  - Design cross-system architectures
  - Solve organization-level problems
  - Drive technical strategy
  - Expert across domains
  
- **Collaboration:**
  - Lead multiple teams technically
  - Mentor senior developers
  - Build engineering culture
  
- **Impact:**
  - Organization-wide technical impact
  - Strategic technical initiatives
  - Industry contributions

## Demonstrating Readiness

### Building Your Case
1. **Document Your Impact**
   - Projects delivered
   - Technical improvements made
   - Team contributions
   - Mentorship provided

2. **Gather Evidence**
   - Code reviews given/received
   - Technical documents written
   - Presentations delivered
   - Open source contributions

3. **Seek Feedback**
   - Regular 1:1s with manager
   - Peer feedback
   - Cross-functional feedback
   - Self-reflection

4. **Create Growth Plan**
   - Identify gaps
   - Set specific goals
   - Timeline for achievement
   - Metrics for success

## What Managers Look For

### Consistent Excellence
- Reliable delivery
- High-quality work
- Positive team impact
- Continuous improvement

### Growing Scope
- Taking on bigger challenges
- Leading initiatives
- Cross-functional impact
- Strategic thinking

### Leadership
- Helping others succeed
- Improving team processes
- Building culture
- Driving decisions

## Staying Current

### Technical Skills
- Learn new languages/frameworks
- Follow industry trends
- Attend conferences
- Read technical blogs
- Contribute to open source

### Leadership Skills
- Take leadership training
- Practice mentoring
- Lead projects
- Build relationships
- Develop communication
