## 📚 Descriptive Variable and Function Names

This repository includes comprehensive examples and guidelines for improving code readability through better naming conventions.

### 📖 Resources

- **[NAMING_GUIDE.md](NAMING_GUIDE.md)** - Complete guide with principles, best practices, and a checklist
- **[naming_examples.py](naming_examples.py)** - 12 Python examples demonstrating good vs. bad naming
- **[naming_examples.js](naming_examples.js)** - 15 JavaScript examples with improved naming patterns
- **[shopping_cart_example.py](shopping_cart_example.py)** - Real-world shopping cart example comparing poor and descriptive naming

### 🚀 Quick Start

```bash
# Run Python examples
python3 naming_examples.py
python3 shopping_cart_example.py

# Run JavaScript examples
node naming_examples.js
```

### 💡 Key Topics Covered

- ✅ Single letter variables → descriptive names
- ✅ Vague names → specific, meaningful names
- ✅ Abbreviations → full words
- ✅ Boolean naming (is/has/can/should prefixes)
- ✅ Function naming conventions (verbs)
- ✅ Constants with clear purpose
- ✅ Loop variables, collections, and time units
- ✅ Context-specific naming

---

**Remember**: Good naming is a sign of professional code. Take the time to choose names that make your code readable and maintainable!
